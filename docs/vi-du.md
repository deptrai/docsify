# Đây là một trang ví dụ

> Đây là cách bạn có thể tạo tài liệu bằng Docsify

## Giới thiệu

Đây là một trang ví dụ để cho thấy cách Docsify hiển thị các file Markdown.

## Ví dụ code

```javascript
function helloWorld() {
  console.log('Xin chào thế giới!');
}
```

## Danh sách công việc

- [x] Tạo trang ví dụ
- [ ] Tạo sidebar
- [ ] Tùy chỉnh giao diện
